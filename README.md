# Premium Todo App 🚀

A modern, high-performance Todo List application built with **Python (FastAPI)** and **Vanilla HTML/CSS/JS**. Designed with a focus on premium aesthetics, featuring glassmorphism effects, smooth animations, and a responsive dark mode interface.

## About
This project demonstrates how to build a full-stack web application using a lightweight yet powerful stack. It avoids heavy frontend frameworks in favor of clean, native web technologies while leveraging the speed of FastAPI for the backend.

### Key Features
-   **FastAPI Backend**: Asynchronous, auto-documenting API.
-   **SQLModel / SQLite**: Simple yet robust ORM for data persistence.
-   **Glassmorphism Design**: Trendy, semi-transparent UI elements.
-   **Dynamic Interactions**: AJAX-based CRUD operations without page reloads.
-   **Responsive & Animated**: Smooth transitions and mobile-friendly layout.

## Setup Instructions

### Prerequisites
-   Python 3.8+
-   pip

### Installation
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/HabibMrad/AntiGravity_testing.git
    cd AntiGravity_testing
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the application**:
    ```bash
    uvicorn main:app --reload
    ```

4.  **Open in Browser**:
    Visit [http://localhost:8000](http://localhost:8000)

## Tech Stack
-   **Backend**: FastAPI, Uvicorn, SQLModel
-   **Frontend**: HTML5, CSS3 (Variables, Flexbox, Animations), JavaScript (ES6+ Fetch API)
-   **Database**: SQLite
